## How to use
1. Click **Open in Colab** for the activity.
2. Set the runtime noted above (`Runtime → Change runtime type`). **Activity 2 needs a T4 GPU.**
3. Run the cells **from top to bottom** with `Shift + Enter`. Read each text cell first; it explains the next step.
4. Look for 💬 **Think** (discussion), 🧪 **Try it** (change & re-run), and 💡 **Key idea** boxes.
5. To keep your changes, use `File → Save a copy in Drive`.
